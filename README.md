# Дудл Джамп — временное расширение для обкатки

Отдельное UI-расширение SillyTavern с одной игрой — вертикальным прыгуном «Дудл Джамп».
Собрано из [STGames](https://github.com/aika636/STGames), чтобы погонять игру на телефоне и
на компьютере **до** того, как она попадёт в основное расширение: обновление STGames
прилетело бы всем, а этого пока не нужно.

Репозиторий временный. Когда игра переедет в STGames, его можно удалить.

## Установка

Extensions → Install extension → ссылка на этот репозиторий. Либо руками — положить папку
в `SillyTavern/public/scripts/extensions/third-party/` и перезагрузить вкладку.

Открыть игру: кнопка «Дудл Джамп» в wand-меню (палочка под полем ввода) или `/djtest`.

## Оно не мешает установленному STGames

Всё, что могло бы столкнуться, разведено:

| Что | STGames | здесь |
|---|---|---|
| Ключ в `extensionSettings` | `STGames` | `DoodleJumpST` |
| Префикс CSS-классов и переменных | `stg-`, `--stg-*` | `djst-`, `--djst-*` |
| Кнопка в wand-меню (id) | `stgames_wand_button` | `djst_wand_button` |
| Слэш-команда окна | `/stgames` | `/djtest` |
| Блоки панели настроек (id) | `stgames_settings_*` | `djst_settings_*` |
| Префикс логов | `[STGames]` | `[DoodleJumpST]` |

Настройки и статистика — свои, отдельные: рекорды, набитые здесь, в STGames не попадут и
наоборот. Слэш-команда самой игры — `/doodlejump`; в STGames её пока нет, так что и она не
конфликтует.

## Игра

Фигурка прыгает сама — игрок только двигает её влево и вправо, стараясь попадать на
платформы. Счёт — максимальная высота; падение ниже нижнего края экрана заканчивает заезд.

- **Клавиатура**: держать `←`/`→`, `A`/`D` или `Ф`/`В`; `Space`/`P`/`З` — пауза;
  `Enter` — новая игра после падения.
- **Тач**: ведение пальцем по полю (палец задаёт, где должна быть фигурка) плюс экранные
  кнопки ◀ ▶ под полем (отключаются в настройках). Пока палец на поле, он задаёт
  направление целиком; отпустили — снова работают кнопки и клавиатура.
- **Платформы**: обычные, движущиеся, рассыпающиеся (срабатывают один раз) и пружины
  (прыжок в 1.6 раза выше).
- **Бустеры**: пропеллер (короткий полёт) и ракета (длинный и быстрый) лежат на обычных
  платформах. Во время полёта гравитации нет и платформы не ловят; остаток видно полоской
  над фигуркой. Отключаются в настройках.
- **Монеты**: лежат на платформах по пути наверх. Счётчик в шапке — за текущий заезд;
  в конце (в том числе если окно просто закрыли) собранное уезжает в кошелёк, и он
  переживает заезды. «Сбросить» в панели статистики кошелёк не трогает.
- **Магазин скинов**: кнопка «Магазин» в шапке и на экране падения. Восемь обликов —
  прыгун, НЛО, призрак, кристалл, капля, звезда, краб и месяц, — и различаются они
  силуэтом, а не только цветом. Покупаются за монеты; купленный надевается сразу, пока
  витрина открыта — партия на паузе. Открытая с экрана падения витрина этот экран прячет
  и возвращает при закрытии: накрыть его собой она не может — в режиме «Цвета таверны»
  окно игры сквозное, и итог заезда просвечивал сквозь плитки.
- **Сложность** (лёгкая/обычная/сложная) меняет зазоры, ширину платформ и долю особых
  типов; переключается на лету и действует на платформы выше текущей высоты.

Генератор не умеет ставить недостижимые платформы: вертикальный зазор ограничен долей от
физически возможной высоты прыжка, а рассыпающаяся платформа никогда не бывает
единственной опорой этажа. Это закреплено тестами.

## Разработка

```bash
node tests/run.mjs                    # все тесты (106)
node tests/run.mjs doodlejump         # то же, фильтром
npm install --no-save jsdom           # нужен только UI-тестам
```

Сборки нет — plain ES-модули и CSS, браузер грузит их напрямую. Ядро игры
(`src/games/doodlejump/core/`) не знает ни о DOM, ни о SillyTavern и тестируется под node.
План, по которому игра сделана, — `docs/plan-doodlejump.md`.
